# Security policy

## Supported public versions

| Release | Support |
|---|---|
| [v1.0.1 (latest)](https://github.com/masarray/arsonverb/releases/tag/v1.0.1) | Current public release; evaluate security issues here |
| v1.0.0 and older | Historical; upgrade to latest before reporting a regression |

ArSonVerb is an audio plugin and standalone program. Do not disable operating system security protections to install it. Release packages may be unsigned/not notarized. Download only from the official [GitHub Releases](https://github.com/masarray/arsonverb/releases) and compare published SHA-256 manifests. Different operating-system warning behavior does not, by itself, indicate a confirmed exploit.

## Privately report a vulnerability

If the repository's **Security → Advisories → Report a vulnerability** option is enabled, please submit a **private vulnerability report** there. If it is not available, open a public [security contact request](https://github.com/masarray/arsonverb/issues/new/choose) **without exploit code, credentials, private logs or other sensitive details**, asking maintainers to arrange a private channel.

Please include: affected version / source commit, impact, attack preconditions, reproducible steps (privately), and any proposed patch. Do not publicly post weaponized proof-of-concept files or other users' data.

Maintainers will investigate and coordinate any fix before disclosure. No response-time SLA or security certification is implied.
