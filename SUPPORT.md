# Help and support

**Download:** [ArSonVerb website](https://masarray.github.io/arsonverb/) · [GitHub Releases](https://github.com/masarray/arsonverb/releases/tag/v1.0.1)

**Installing:** See [Windows, macOS and Linux instructions](docs/RELEASE_V1.0.1.md). For DAWs, download **VST3-only** for your OS, unpack the full bundle, place it in the OS VST3 folder, reopen the DAW and rescan. The Windows Inno installer ZIP is optional.

**No sound?** Check DAW plugin bypass, host input/output channel layout, the wet/dry Mix control and track routing. For a send/aux use 100% wet and maintain a separate dry signal; for inserts start around 15–25% Mix.

**Dropouts, glitches or crashes?** Record OS, DAW and version, audio device/driver, sample rate, callback buffer size, plugin version, loaded count, active preset/algorithm and steps to reproduce. Hardware latency and xruns are setup-dependent; no software plugin can guarantee a zero-latency device path.

**Browser download warnings?** Archives are ordinary GitHub release ZIP/tar.gz packages; do not use unknown mirrors or switch off system security. SHA-256 manifests are published alongside the binaries.

**Bug or feature request:** [Open a structured issue](https://github.com/masarray/arsonverb/issues/new/choose). Include a minimal reproducer, not just a screenshot of an error. Review [known limits](docs/QUALITY_STATUS.md) first.
