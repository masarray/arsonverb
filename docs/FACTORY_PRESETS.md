Catalog API is JUCE-independent, constexpr internally, and read-only in the audio path. Preset IDs are stable C++ numeric indices; VST3 menu IDs are indices + 1. Values require listening QA; numeric matching to a Valhalla mode is neither claimed nor meaningful without identical algorithms.
