## Same-runner Linux 54-scenario P1/P2 comparison

The two executables were compiled with the same C++17 -O3 flags on the same runner. P2 removed five unused per-sample smoothing integrations. The sample is short/noisy; no numeric threshold was used to artificially pass.

| Scenario (16 serial instances + automation) | P1 p99 | P2 p99 | Relative |
|---|---:|---:|---:|
| 48 kHz, block 32 | 113.682 μs | 104.335 μs | −8.22% |
| 96 kHz, block 32 | 114.894 μs | 116.748 μs | +1.61% |
| 192 kHz, block 32 | 138.018 μs | 122.148 μs | −11.50% |
| 192 kHz, block 256 | 848.986 μs | 833.697 μs | −1.80% |

Across all 54 scenarios, median p99 delta **+0.30%** and median mean **+0.36%**, so the data are inconclusive about global CPU speedup. Both variants recorded zero *offline* callbacks above theoretical deadlines. No actual DAW glitch-free assertion can be made from these tests.
