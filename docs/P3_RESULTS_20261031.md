# ArSonVerb P3 — Verified Musical Room Structure (2026-10-31)

**Source:** [merged PR #22](https://github.com/masarray/arsonverb/pull/22) · commit `36f4538619e1dee92cc25ddc6e1a9768bf0f1eca`.

## Audio engine milestone

- Early-to-late smooth morph: six existing early stereo reflections and four existing allpass diffusers; increasing Diffusion beyond 0.62 blends modest additional stereo crossfeed/early send. **Zero additional delay taps/read operations**, no extra buffer memory.
- Low-frequency feedback decay: a single one-pole spectral contour in the Householder reflection eigenmode, controlled by the pre-existing Wet Low Cut (and coefficient-smoothed); no full multiband EQ and no change to plugin dry path.
- Stable ABI and GUI: 13 parameter automation IDs and 32 factory preset numeric settings; original gold hardware GUI/precision controls, bypass, C API and no extra sample latency.
- This changes musical voicing; compatibility of control IDs and values **does not imply bitwise sound identity** with P2.
